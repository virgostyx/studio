# **App Name**: Office Tracker

## Core Features:

- Check-In Feature: Allow employees to check in when they arrive at the office.
- Check-Out Feature: Allow employees to check out when they leave the office.
- Live Presence List: Display a list of currently present employees in real-time.

## Style Guidelines:

- Primary color: Light blue (#B0E2FF) for a calm and professional feel.
- Secondary color: Light gray (#E0E0E0) for backgrounds and subtle contrasts.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clear and legible sans-serif fonts for ease of reading.
- Simple and intuitive icons for check-in and check-out actions.
- Clean and organized layout with a focus on displaying the employee list prominently.

## Original User Request:
I would like to build an employee presence tracker. When entering into the office, the employee will check in and check out when leaving the office. it will allow to have at any time a list of employee currently in the office. This list will be used for security reason
